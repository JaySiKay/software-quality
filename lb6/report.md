## Результати тестування

### TC-01. Успішна авторизація

**Передумова:** відкрита сторінка авторизації.

**Test Data:** Username = `standard_user`, Password = `secret_sauce`.

**Кроки:**
1. Ввести логін і пароль.
2. Натиснути Login.

**Expected Result:**  
Після введення правильного логіна та пароля відкривається сторінка каталогу товарів.

**Actual Result:**  
Після натискання Login відкрилася сторінка `inventory.html`, відобразився заголовок Products.

**Status:** Passed

### TC-02. Неправильний пароль

**Передумова:** відкрита сторінка авторизації.

**Test Data:** Username = `standard_user`, Password = `wrong_password`.

**Кроки:**
1. Ввести логін і неправильний пароль.
2. Натиснути Login.

**Expected Result:**  
Авторизація не виконується, відображається повідомлення про помилку.

**Actual Result:**  
Користувач залишився на сторінці авторизації, відобразилась помилка з текстом "Epic sadface: Username and password do not match any user in this service".

**Status:** Passed

### TC-03. Додавання товару

**Передумова:** користувач відкрив SauceDemo.

**Test Data:** Username = `standard_user`, Password = `secret_sauce`, Товар = `Sauce Labs Bolt T-Shirt`.

**Кроки:**
1. Відкрити SauceDemo та авторизуватися.
2. Додати `Sauce Labs Bolt T-Shirt` до кошика.
3. Перевірити індикатор кошика.
4. Відкрити кошик.
5. Перевірити назву товару в кошику.

**Expected Result:**  
Індикатор кошика показує `1`, вибраний товар відображається в кошику.

**Actual Result:**  
Після натискання кнопки додавання індикатор кошика показав `1`, у кошику відобразився товар `Sauce Labs Bolt T-Shirt`.

**Status:** Passed


## Аналіз результатів

Під час запуску `npx playwright test` було успішно виконано 3 тести, усі завершилися зі статусом Passed. Фактичні результати кожного тесту збіглися з очікуваними, що підтверджує коректну роботу авторизації, обробки неправильних облікових даних та додавання товару до кошика у SauceDemo.
